# Cardinal Query skill

A standalone GitHub Copilot skill for searching Cardinal Data Lake logs and investigating recurring Issues. It connects to your Data Lake Query API with an organization API key.

The first release is pending review. Release packages will be listed on the [Releases page](https://github.com/cardinalhq/cardinal-query-skill/releases).

The source is maintained in [Cardinal Agent Plugins](https://github.com/cardinalhq/cardinal-agent-plugins).
