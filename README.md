# Cardinal Query skill

Search Cardinal Data Lake logs and investigate recurring Issues from GitHub Copilot. The skill uses Python 3.9+ and connects directly to your hosted Query API with an organization API key.

1. Download the [v0.1.0 skill ZIP](https://github.com/cardinalhq/cardinal-query-skill/releases/download/v0.1.0/cardinal-query.zip).
2. Extract it and copy the entire `cardinal-query` folder into `.github/skills/cardinal-query` in your repository.
3. Follow the [setup guide](.github/skills/cardinal-query/references/setup.md) for credentials and instructions for Copilot CLI, IntelliJ, and GitHub.com agent sessions.

This repository distributes the reviewed skill from [Cardinal Agent Plugins](https://github.com/cardinalhq/cardinal-agent-plugins/tree/64f7d30097fd9137242154603d008e3167960802/.github/skills/cardinal-query).
